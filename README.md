# CareerCraft 🎯

**AI-powered career guidance platform.** Upload your resume, get it analyzed by Gemini AI, discover the careers that fit your skills, follow a personalized roadmap, test yourself with AI-generated assessments, and find matching job openings with direct apply links.

🔗 **Live Demo:** _add your Streamlit link here_

---

## ✨ Features

- **Auth**: Register / login with JWT-based authentication
- **Resume Analysis**: Upload a PDF resume; Gemini extracts skills, education, projects, experience, and missing skills
- **Career Recommendations**: Careers ranked by how well they match your skills
- **Personalized Roadmap**: Skill-by-skill learning roadmap with progress tracking
- **AI Skill Assessments**: 5-question MCQ quizzes generated by Gemini; score 60%+ to complete a skill
- **Job Matching**: Openings ranked by skill match, with a direct **Apply** link

## ⚙️ Run Locally

**1. Clone & install**
```bash
git clone https://github.com/bhanuduhoon77/CareerCraft.git
cd CareerCraft
python -m venv venv
venv\Scripts\activate          # Windows
pip install -r backend/requirements.txt
pip install streamlit
```

**2. Create `.env` in the project root** (see `.env.example`)
```
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=careercraft
GEMINI_API_KEY=your_gemini_key
SECRET_KEY=any_long_random_string
```

**3. Start the backend**
```bash
uvicorn backend.main:app --reload
```
Tables are created automatically. Seed jobs with `python -m backend.seed_jobs`.

**4. Start the frontend** (new terminal)
```bash
streamlit run streamlit_app.py
```

## ☁️ Deployment

- **Database**: hosted MySQL (Aiven / TiDB Cloud), set `DB_SSL=true`
- **Backend**: Render, start command `uvicorn backend.main:app --host 0.0.0.0 --port $PORT`
- **Frontend**: Streamlit Community Cloud, with `API_BASE_URL` set in app secrets
